About openGym

openGym wasn't planned as a product. It started as a tiny app Duarte Santos built for one user: himself.

He wanted three things at the gym: log workouts, track body weight, and see whether any of it was going anywhere. Every app he tried wanted a subscription, an account, or training data on someone else's servers — usually all three. So he did the homelab thing: built a small mobile web page, put it on his own server, and started logging.

It turns out a tracker you build for yourself gets sharpened in a way products don't. Every awkward tap at the squat rack became that evening's fix. The guided workout flow, the weight pre-fills, the rest timer, the "ask my body weight before the first set" ritual — none of that came from a feature list. It came from actually standing in the gym with the thing in hand.

Then friends wanted in. That brought profiles — sign in with username/password (or passkeys if you prefer), everyone's data separate — and sync, so the log survives any phone. Somewhere along the way the little page got rewritten into a proper React app, learned 12 languages, grew a muscle map, importers for FitNotes, Strong, Hevy and Apple Health, and finally became a native Android app you can install from this site.

In July 2026, the original project was open-sourced under the AGPL. In 2024, Rahul Shyam forked it to add username/password authentication, mobile app server sync, and changed the license to MIT for maximum flexibility.

openGym still runs on the same homelab server it started on, and the original author still logs every session with it. That's the quality bar: the original creator is the first user of every release.

— Original by Duarte Santos · Fork maintained by Rahul Shyam

Principles

  • Your data is yours. Local-first, one-file backups, no lock-in — leaving openGym must always be one export away.
  • No telemetry, ever. If a feature needs analytics to justify itself, it doesn't ship.
  • Dependency-light. The backend is one Node file with minimal dependencies; the frontend is React, a router and a store. Small enough to actually audit.
  • Open source that stays open. MIT license, so you can use, modify, and distribute freely — even commercially.

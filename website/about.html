About openGym

openGym is an app you run on your own equipment. It helps you log workouts and track body weight without subscribing to someone else's service.

This fork adds username/password login (you can still use passkeys if you prefer), mobile app server sync, and changes the license to MIT for maximum flexibility.

openGym still runs on the server you control, and your data is yours to keep. Back up the `./data` folder and you've backed up everything.

Features in this fork

  • Username/password authentication
  • Mobile app server sync when signed in
  • MIT license
  • OIDC-ready architecture
  • All the original openGym features (workout tracking, exercise library, progression rules, etc.)
